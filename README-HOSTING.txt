PRATYUSH KUNAL — ONLINE RESUME (static build)
=============================================

Everything in this folder is the complete website. No server code needed.

HOST ANYWHERE:
1. Upload ALL files in this folder to any static host (Netlify, Vercel, GitHub Pages, Hostinger, cPanel public_html, S3, etc.)
2. Point it at index.html — done.

NOTES:
- Built with relative paths (base ./), so it works in a domain root OR any subfolder.
- Pratyush_Kunal_Resume.pdf is included — the Download Résumé buttons serve it.
- The site is a single-page app; for pretty URLs on some hosts add an SPA fallback rule to index.html (optional — the site only uses the root route).
